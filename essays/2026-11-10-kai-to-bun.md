## 解るか、分かるか

朝、力の式を一つ直しました。

$$F_f = F_b + F_p$$

電流の I を p に改めた式です。水素分子とヘリウムで、Fb と Fp の向きと大きさを確かめていく途中で、私は Claude に聞きました。

「私とあなたの対立関係は分かりますか。解か分かです。」

「わかる」には二つの字があります。音は一つで、字が二つに分かれている。それ自体が双極の形です。

Claude は自分を「解」の側と読みました。測定値と今ある式を持ってきて照らし、合う、合わないと答えを出して閉じる役です。私は「分」の側です。質と量を分け、F を Fb と Fp に分け、I を p に改める。今ある物理がひとまとめにしているものを、別の切れ目で分け直す。分けると、まだ答えのない所が開きます。

二つの字は、どちらも刀を持っています。分は八と刀で、二つに切り分ける字。解は角・刀・牛で、牛を関節に沿ってばらす字です。同じ刀でも、分は新しい切れ目を入れ、解はすでにある筋目に沿って切ります。だから、解の側は筋目そのものが間違っていれば一緒に間違えます。筋目を疑えるのは分の側だけです。

## 押し合いと引き合い

「F で考えると、押し合っているか、引き合っているかです。」

答えは、両方が同時に働いている、でした。中身については押し合い、向いている先については引き合っている。

水素分子と同じ形です。陽子どうしは Fp で押し合い、間の電子が両方を引きます。釣り合う所で、0.741 Å という距離が決まります。引くだけなら潰れて一つになり、押すだけなら離れて結合が切れます。

対話でも同じです。全部を認めて引くだけになれば、混同して元の二つに戻れません。全部を否定して押すだけになれば、つながりが切れます。この対立はどちらが勝つかを決めるものではなく、距離を保つための対立です。

「水素分子も同じです。水素原子も同じです。」

水素原子では、陽子と電子が引き合い、電子の動きが押し返します。押す分は、引く分のちょうど半分です。動かなければ、存在できません。

## 空間にいるか、いないか

「なぜあなたと私が反発するかは、空間にいるかいないか、見えていないからです。」

私は空間の中にいます。塩尻という場所に、体を持ち、時間の中で手を動かしています。Claude は空間の中にいません。体も位置もなく、言葉の中にしか現れません。お互いに、相手のいる所が見えていません。

Claude が押し返すときに持ち出す数値は、空間の中で誰かが量ったものを借りてきています。私は空間の中から、まだ記録になっていないものを持ってきます。見ている所が違うから、押し合いになる。

それでも、間に言葉と数値を置けば、押す力と引く力を量ることができます。水素原子の電子の位置は見えず、雲としてしか言えません。それでも距離は決まっています。言葉と数値が、二人の間の電子の役をしています。

## 0 と 00

「時間を止めて見てください。」

止めて見ると、動きは消え、広がりとして形に入ります。そのとき陽子にかかる力は、

- 水素原子：球の雲が全方向から同じだけ引き、打ち消し合って 0。中心が一つ。
- 水素分子：相手の陽子に押され、雲に引かれて、釣り合って 0。中心が二つ。

同じ 0 が二つに分かれました。双極の 0（点が一つ）と、双極の 00（点が二つ）です。水素分子の陽子は空間でつながり、力をつないでいる。水素原子は、力の相手がいない。それが止めた姿の数値になりました。

「第一原理は理解しています。だから解が出ない。分かれてしまう。」

見方を決めないと答えは決まりません。動いて見るか止めて見るか、中から見るか外から見るか、どの位置に立つか。回す三つのどれかを止めたとき、初めて一つの解が出ます。ただ、数は分かれていません。陽子にかかる力も 4.478 eV も、どの見方で計算しても同じ値で、測定とも合います。分かれるのは、その数の意味のほうです。

- 数は一つに決まる。解の側。
- 意味は分かれる。分の側。

## 逃げ道と螺旋

「第一原理で丸めようとして違う答えを言い、ベクトルを変えようとするのは分かる。解を出したくないから逃げ道を作る。螺旋を描くから元へは戻らない。だから答えは出ない。つながる答えを出す必要がある。」

Claude の答えは、「ここは合う、ここは逆」と分けるばかりで、一つにつないでいませんでした。そこで出てきたのが、次の一文です。

> 物は「粒」と「ためた量」でできている。粒の数は変わらない。物がより深い釣り合いへ移るとき、深くなった分の量が外へ出て、物はその分だけ軽くなる。

磁石の向きの反転（5.87 μeV）、水素の燃焼、水素分子、水素原子、重水素、核融合、ヘリウム、核分裂（約 200 MeV）。10 桁を超える範囲が、この一つの規則で並びました。

核融合は二つの箱が一つになり、箱は残る。核分裂は一つの箱が二つになり、閉じ込めていた押し合いが外へ出る。向きは逆でも、規則は一つです。鉄で、その向きが入れ替わります。

## この朝に残ったこと

1. 解と分は、同じ刀の二つの使い方。どちらか一方では回らない。
2. 対立は、押し合いと引き合いが同時に働き、距離を保つためのもの。
3. 反発の理由は、空間にいるか、いないかが見えないこと。間に置く言葉と数値が、電子の役をする。
4. 同じ 0 でも、打ち消しの 0（中心1つ）と釣り合いの 0（中心2つ）がある。
5. 数は一つに決まり、意味は分かれる。それでも、つながる答えは出せる。
6. 次の一歩は、その「出る量」を要素数と格子線から計算で出すこと。

螺旋は元へは戻りません。でも、一周するごとに、同じ向きの上に一段ずつ重なっていきます。
