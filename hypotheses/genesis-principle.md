## 2. 中心はベクトルの総和 0 で決まる

ある点から各点へ向かうベクトルの総和が 0 になるとき、その点が中心（重心）です。

$$\sum_i \vec{r}_i = \vec{0}$$

正四面体では、中心から4頂点へ向かうベクトルの総和が 0 になります。4本はどれも「有」ですが、合わせると「無」になります。

中心の位置は時間に依存します。

$$\vec{R}(t) = \frac{\sum_i m_i \vec{r}_i(t)}{\sum_i m_i}$$

**主張**：中心点は、時間をどこで切るかによって決まります。

**既存物理との対応**：相対論では「同時」が観測者によって違います。そのため、動く系の重心は観測者ごとに異なり、一つに定まりません。中心を決めるには「いつ」と「誰から見て」の両方が必要です。

## 3. 力を合わせると一つ

二つの力をベクトルとして足すと、一本の合力になります。大きさが等しく向きが反対の場合は、次の二つに分かれます。

1. 同じ線上にあれば、合力は 0 になります。
2. 線がずれていれば、合力は 0 でも**偶力**が残り、物体は回転します。

**主張**：双極の FF は二つの顔を持ちます。

| 演算 | 結果 | 意味 |
|---|---|---|
| ベクトル和 | 0 | 中心が決まる（双極の 00） |
| 対として一組 | 1 | FF = 1（UM = 1） |

> **記述上の注意**：同じ FF で「0」と「1」の両方を言うときは、**どの演算での値か**を必ず書き分けます。書き分けないと、読み手には 0 = 1 と読めてしまいます。

**双極の 00 は双極の FF です。**

## 4. 分けられないもの

| 対象 | 分けられるか |
|---|---|
| BP（二本のポール） | 2つに分けられる |
| FF（力・力） | 2つに分けられる |
| **OπO** ＝ XUY ＝ JAΦ | **分けられない** |

**主張**：これ以上小さくならないエネルギーが OπO です。

### 4.1 OπO を FF で分ける

エネルギーを力で割ると、単位は長さになります。

$$\frac{\mathrm{J}}{\mathrm{N}} = \mathrm{m}$$

プランク単位では、次のようになります。

$$\frac{E_P}{F_P} = \frac{\sqrt{\hbar c^5/G}}{c^4/G} = \sqrt{\frac{\hbar G}{c^3}} = l_P \approx 1.616 \times 10^{-35}\ \mathrm{m}$$

$\hbar = G = c = 1$ とすると、$E_P = F_P = l_P = 1$ です。

**主張**：分けられないエネルギー（OπO）を FF = 1 で分けると、量は保たれたまま、エネルギーから長さへと姿が移ります。**空間はこうして現れます。**

**既存物理との対応と注意**

- プランク定数 $h = 6.62607015 \times 10^{-34}\ \mathrm{J\,s}$ は**作用**の最小単位です。長さでもエネルギーでもありません。
- 標準物理には、宇宙共通の「最小エネルギー」はありません。$h\nu$ は振動数によって、いくらでも小さくなれます。
- 近い概念は**零点エネルギー** $E_0 = \tfrac{1}{2}\hbar\omega$ です。0 にはならないが無でもない、という性質を持ちますが、ω に依存します。
- $E_P / F_P = l_P$ は単位の関係から必ず成り立つ式です。プランク長が「分けられない最小の長さ」であることを証明するものではありません。
- **課題**：OπO を定数だけで決まる量として、式で示すこと。→ §13 で光速・力・ħ による式を示しました。

## 6. 関係は時間を必要としない

**主張**：この関係（作用・反作用）は時間を必要としません。

**既存物理との対応**

| | 時間 |
|---|---|
| 関係そのもの（保存則） | 不要。常に成り立つ |
| 関係が相手に届くこと | 離れていれば必要（場を通して光速で伝わる） |

動く電荷どうしでは、作用と反作用が瞬間ごとには釣り合わないことがあります。それでも、場が運動量を運ぶので、全体の保存は保たれます。

**関係は時間なしに決まり、中心の位置は時間を決めて初めて定まります。**

## 12. 境界は接点

**主張**：精神論も、この視点から見れば物理とつながっています。数学は数で関係性を表そうとする学問であり、これもつながっています。宇宙のすべてがつながっていて、境界もつながっています。

直線と円の関係は、中心から直線までの距離 $d$ と半径 $r$ で決まります。

| 関係 | 交点 | 意味 |
|---|---|---|
| $d > r$ | 0 | 離れている |
| $d = r$ | 1（接する） | **境界でつながる** |
| $d < r$ | 2（交わる） | **境界で分けられる** |

直線と円の式を連立すると二次方程式になります。接するとき、その解は**重解**です。

$$\text{判別式} = 0 \iff \text{接する}$$

**接点は、二つの交点が重なって一つになった点です。**

| 二つが一つになるもの | |
|---|---|
| W | U が二つで一文字 |
| FF | 力が二つで 1 |
| 接点 | 交点が二つで 1 点 |

**境界は二つを隔てるものではなく、二つが一つにつながる所です。**

## 13. OπO を光速と力で表す

**主張**：OπO は、光速と F の関係式で作れます。質量は、質と量の関係を示さなければなりません。

### 13.1 c と F だけでは閉じない

| 量 | 次元 |
|---|---|
| エネルギー | M L² T⁻² |
| 力 F | M L T⁻² |
| 光速 c | L T⁻¹ |

$F^a c^b$ でエネルギーを作ろうとすると、M から $a=1$、L から $b=1$ が決まります。このとき T は $-3$ となり、必要な $-2$ に合いません。**c と F の二つだけでは、エネルギーは作れません。**

### 13.2 ħ を加えると閉じる

$$O\pi O = \sqrt{\hbar\, c\, F}$$

次元の確認：

$$\hbar c F \;\to\; (\mathrm{M L^2 T^{-1}})(\mathrm{L T^{-1}})(\mathrm{M L T^{-2}}) = \mathrm{M^2 L^4 T^{-4}} = (\mathrm{M L^2 T^{-2}})^2$$

F にプランク力 $F_P = c^4/G$ を入れると、次のようになります。

$$O\pi O = \sqrt{\hbar c \cdot \frac{c^4}{G}} = \sqrt{\frac{\hbar c^5}{G}} = E_P$$

| 入るもの | 役割 |
|---|---|
| c と F（$F_P = c^4/G$） | 重力（G は光速と力の関係で決まる） |
| ħ | 量子（作用の最小単位） |

あわせて、長さは次のように出ます。

$$\frac{O\pi O}{F} = \sqrt{\frac{\hbar c}{F}} \;\xrightarrow{F=F_P}\; \sqrt{\frac{\hbar G}{c^3}} = l_P$$

**既存研究との対応**：$c^4/G$（または $c^4/4G$）を、自然界で取りうる**最大の力**とみなす仮説があります（Gibbons、Schiller ほか）。確立した法則ではありませんが、「F が c で決まる上限を持つ」という見方と重なります。

### 13.3 質量 ＝ 質と量

$$m = \frac{O\pi O}{c^2} = \sqrt{\frac{\hbar F}{c^3}} \;\xrightarrow{F=F_P}\; \sqrt{\frac{\hbar c}{G}} = m_P$$

物理の質量には二つの顔があり、等価原理によって両者は等しくなります。

| 顔 | 意味 |
|---|---|
| 慣性質量 | 動かしにくさ（力にどう応じるか） |
| 重力質量 | 重力の源（どれだけあるか） |

**未決**：「質」と「量」がそれぞれ何に対応するかは、まだ決まっていません。README の仮説1（重力も慣性も「量」で決まる）との整合が必要です。対応の候補は次のとおりです。

- $m = E/c^2$ の $E$ を**量**、$1/c^2$ を**質**（エネルギーを質量へ変える性質）と読む
- 慣性質量と重力質量の対を、質と量の双極として読む

## 14. 融合・分裂と鉄、そしてブラックホール

### 14.1 主張

- **核融合**には力が必要です。2空間のものを1空間にするには、エネルギーが要ります。
- **核分裂**は、1空間の質量を2空間にします。そのため、エネルギーが放出されます。
- **鉄（Fe）**は分裂も融合もしません。その先では、消滅によってエネルギーに変わることになります。これがブラックホールにつながっているのではないか、と考えます。

### 14.2 入口：障壁を越える力

二つの原子核を一つにするには、正の電荷どうしの反発（クーロン障壁）を越えて近づける必要があります。太陽の中心では、約1500万度の熱と重力による圧縮がこの役目を担っています。

**「2空間を1空間にするには力（エネルギー）が要る」は、入口については常に成り立ちます。**

### 14.3 出口：鉄を中心に向きが反転する

正味の収支は、核子1個あたりの結合エネルギーで決まります。この値は鉄（Fe-56）付近で最大になります。

| | 鉄より軽い核 | 鉄より重い核 |
|---|---|---|
| 融合（2 → 1） | **放出**（太陽、水爆） | 吸収 |
| 分裂（1 → 2） | 吸収 | **放出**（原子炉） |

どちらの場合も、反応の後で減った質量 $\Delta m$ が次の式でエネルギーとして出てきます。

$$E = \Delta m\, c^2$$

**鉄は、融合しても分裂してもエネルギーを取り出せない点であり、結合エネルギー曲線の頂上です。** 両側から坂を下ってきて、ここで止まります。§12 の「接点」と同じく、鉄は二つの向きが一つに出会う境目です。

### 14.4 鉄の先：重力崩壊からブラックホールへ

**既存物理との対応**（恒星進化の標準的な理解）

1. 重い星（太陽の約8倍以上）は、中心で水素 → ヘリウム → 炭素 → … と順に融合し、そのエネルギーで重力に抗っています。
2. 中心が鉄になると、融合してもエネルギーが出ず、支えを失います。
3. 鉄の核は重力に負け、1秒もかからずに崩壊します。このとき鉄は光で分解され、エネルギーを吸収します。
4. 超新星爆発が起き、中心は**中性子星**か**ブラックホール**になります。

**「鉄は融合も分裂もしない → ブラックホールにつながる」という筋は、恒星進化の標準的な理解と一致します。**

### 14.5 「消滅」をどこに置くか

| 段階 | 起きること | 質量の行方 |
|---|---|---|
| 重力崩壊 | 莫大なエネルギーの放出（大半はニュートリノ） | 重力の位置エネルギーが出る。鉄の質量が消えるのではない |
| ブラックホール | 質量を閉じ込める | 消えずにブラックホールの質量として残る |
| 蒸発（ホーキング放射） | 質量が放射に変わる | **ここで質量がエネルギーになる** |

> **記述上の注意**：物質がまるごとエネルギーに変わる「消滅」は、粒子と反粒子が出会うときに起きます。鉄そのものは消滅しません。星の質量のブラックホールが蒸発するには、$10^{67}$ 年以上かかります。

**流れ**

```
軽い核 ─融合→ 鉄 ←分裂─ 重い核
             │（どちらの向きもエネルギーを出さない）
             ▼
          重力崩壊
             ▼
        ブラックホール
             ▼  ホーキング放射
       質量 → 放射（消滅）
```

**残る問い**：ブラックホールの蒸発で放射に変わったエネルギーは、§4 の OπO（分けられないエネルギー）、そして §11 の「宇宙の誕生」とどうつながるか。
