# 参照する方程式

このファイルは、JA0XUY-BPFF が参照する確立した方程式と、その出典をまとめたものです。
方程式そのものは書き換えません。各方程式の下に、BPFF の作業仮説がどの項に対応するかを記します。

番号付きの出典は README の「参考文献」と共通です。

---

## 1. アインシュタイン方程式（宇宙項つき）

出典：[1] Einstein 1915、[2] Einstein 1917

$$G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$$

| 記号 | 意味 |
|---|---|
| $G_{\mu\nu}$ | アインシュタイン・テンソル（時空の曲がり） |
| $g_{\mu\nu}$ | 計量テンソル |
| $\Lambda$ | 宇宙項（宇宙定数） |
| $T_{\mu\nu}$ | エネルギー・運動量テンソル（重力の源） |
| $G$ | 万有引力定数 |
| $c$ | 光速 |

**BPFF との対応**

- 仮説1：$T_{\mu\nu}$ に入るのは「量」。慣性も量で決まるので、等価原理と整合する。
- 仮説2：真空の「質3」は、空間の内側では $T_{\mu\nu}$ の局所的な源にならない。
- 仮説3〜5：有と無の張力は、$\Lambda g_{\mu\nu}$ の項として現れる。

## 2. 真空エネルギーと宇宙項の関係

出典：[4] Weinberg 1989

真空のエネルギー密度 $\rho_{\text{vac}}$ は、宇宙項と次の関係にあります。

$$\Lambda_{\text{eff}} = \Lambda + \frac{8\pi G}{c^2}\rho_{\text{vac}}$$

一様な真空は、負の圧力を持つ流体として振る舞います。

$$p_{\text{vac}} = -\rho_{\text{vac}}\,c^2$$

**BPFF との対応**

- 仮説3：有と無の張力が空間のつながりを通じて一様に伝わることが、この負の圧力（張力）にあたる。
- 仮説5：単位胞ごとの $XY=1$ とベクトル総和0により、張力の正味の値は厳密に0。

## 3. フリードマン方程式（平坦な宇宙）

出典：[3] Friedmann 1922

$$H^2 = \left(\frac{\dot a}{a}\right)^2 = \frac{8\pi G}{3}\rho$$

| 記号 | 意味 |
|---|---|
| $a$ | スケール因子（宇宙の大きさの比。現在を1とする） |
| $H$ | ハッブル・パラメータ（膨張率） |
| $\rho$ | 全エネルギー密度（質量密度換算） |

平坦な宇宙の全密度は、臨界密度と等しくなります。

$$\rho_c = \frac{3H^2}{8\pi G}$$

プランク密度との比は、ハッブル半径 $R_H = c/H$ を使って次のように書けます。

$$\frac{\rho_c}{\rho_{\text{Planck}}} = \frac{3}{8\pi}\left(\frac{l_P}{R_H}\right)^2$$

**注意**

この式は、宇宙の大きさを入力にすると $(l_P/R)^2$ の形が自動的に出てくることを示しています。$(l_P/R)^2$ の形を、TTT の予言として使うことはできません。

## 4. 流体の連続の式と密度変化

出典：[3] から導かれる標準的な関係

$$\dot\rho + 3H\left(\rho + \frac{p}{c^2}\right) = 0$$

状態方程式 $p = w\rho c^2$ で $w$ が一定のとき、密度は次のように変わります。

$$\rho \propto a^{-3(1+w)}$$

| w | 密度の変わり方 | 例 |
|---|---|---|
| 0 | $a^{-3}$ | 物質 |
| 1/3 | $a^{-4}$ | 放射 |
| −1/3 | $a^{-2}$ | 加速の境目（加速しない） |
| −1 | 一定 | 宇宙定数 |

加速膨張には $w < -1/3$ が必要です。

**BPFF との対応**

- 仮説4：$XY=1$ が単位胞ごとに成り立つので、密度は一定、$w = -1$。

## 5. 暗黒エネルギーの状態方程式の時間変化（CPL 形式）

出典：[5] Chevallier & Polarski 2001、[6] Linder 2003

$$w(a) = w_0 + w_a(1-a)$$

| 記号 | 意味 |
|---|---|
| $w_0$ | 現在の w |
| $w_a$ | w の時間変化の大きさ |

宇宙定数は $w_0 = -1,\ w_a = 0$ です。

**BPFF との対応**

- 予言：$w_0 = -1,\ w_a = 0$。
- 観測の現状は [7] DESI DR2、[8] Turyshev 2026 を参照。$w_0 > -1,\ w_a < 0$ の傾向が確定すれば、仮説4は否定されます。

## 6. プランク単位

出典：標準的な定義（数値は CODATA 2018）

$$l_P = \sqrt{\frac{\hbar G}{c^3}},\qquad t_P = \frac{l_P}{c},\qquad \rho_{\text{Planck}} = \frac{c^5}{\hbar G^2}$$

**BPFF との対応**

- $O\pi O = l_P$（最小の長さ）。
- 仮説7：時間の単位は、0から光速に達するまでの時間。$t_{\text{単位}} = O\pi O / c = t_P$。
