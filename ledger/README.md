# 矛盾台帳（Contradiction Ledger）― 初版

**開始**：2026-11-22
**記録**：川上真潔（Kawakami Naoyuki）、Claude
**本文**：[`../toward-a-first-principle/06-no-side.md`](../toward-a-first-principle/06-no-side.md)

## 目的

各国が、戦争ごとにどの「見る位置」（サイド）を使っているかを、出典つきで並べる。
同じ国が別の戦争で別の基準を使っているところ（矛盾）を、誰でも確かめられる形で示す。

断定はしない。**事実を並べ、問いを出す。** 判断は読む人に委ねる。

## 規則

1. 1 行 1 事実。出典（URL と日付）のない行は入れない。
2. 動機（「覇権を目論む」など）は書かない。書くのは発言・行動・加盟状況などの確かめられる事実だけ。
3. 見る位置は次の 5 つから選ぶ：`当事者`・`秩序`・`均衡`・`損得`・`失われる者`。
4. 矛盾の指摘は `question` 列に「問い」の形で書く。
5. 誤りの指摘を受けたら、行を消さずに `status` を `訂正` にして、訂正内容を新しい行で追加する（履歴を残す）。

## 列

| 列 | 意味 |
|---|---|
| id | 通し番号 |
| date | 事実の日付 |
| actor | 国・組織 |
| war | 対象の戦争・問題 |
| position | 見る位置（5 種） |
| fact | 確かめられる事実（要約） |
| source | 出典名 |
| url | 出典 URL |
| question | その事実から出る問い（任意） |
| status | `記録`・`確認待ち`・`訂正` |
